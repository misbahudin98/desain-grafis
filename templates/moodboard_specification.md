## 1. STRUKTUR KURASI MOODBOARD KANONIKAL

Sebuah moodboard kelas dunia tidak boleh menjadi tumpukan gambar acak tanpa benang merah. Moodboard harus dikurasi ke dalam **5 Kuadran Resonansi Visual**:

```
┌─────────────────────────────────┬─────────────────────────────────┐
│ [KUADRAN 1: COLOR & LIGHT]      │ [KUADRAN 2: TEXTURE & MATERIAL] │
│ - Palet 5 warna utama (HEX)     │ - Makro material nyata (kayu,   │
│ - Karakter cahaya (Key/Shadow)  │   marmer, linen, logam sikat)   │
├─────────────────────────────────┼─────────────────────────────────┤
│ [KUADRAN 3: COMPOSITION & SPACE]│ [KUADRAN 4: TYPOGRAPHY & FORM]  │
│ - Geometri kisi-kisi (Swiss)    │ - Karakter glif huruf           │
│ - Luas ruang negatif (Whitespace│ - Hirarki judul vs bodi         │
├─────────────────────────────────┴─────────────────────────────────┤
│ [KUADRAN 5: NARRATIVE EMOTION & KEYWORD ANCHORS]                  │
│ - 5 Kata Kunci Emosional Utama (Contoh: Timeless, Muted, Solitary)│
└───────────────────────────────────────────────────────────────────┘
```

## 2. FORMULIR SPESIFIKASI PROYEK

- **Nama Proyek:** [Nama Proyek / Kampanye]
- **Target Audiens:** [Profil demografis & psikografis pembaca/penonton]
- **5 Kata Kunci Jangkar (Keyword Anchors):**
  1. `[Kata Kunci 1, misal: Stoic]`
  2. `[Kata Kunci 2, misal: Tactile]`
  3. `[Kata Kunci 3, misal: Monolithic]`
  4. `[Kata Kunci 4, misal: Chiaroscuro]`
  5. `[Kata Kunci 5, misal: Unhurried]`
- **Inspirasi Referensi Desainer / Sinematografer:** (Misal: Roger Deakins, Peter Zumthor, Dieter Rams, Massimo Vignelli).
- **Emulasi Film Stock:** (Misal: Kodak Portra 400 untuk potret / Kodak Vision3 500T untuk malam).
- **Larangan Visual (Anti-Vision):**
  - Dilarang warna saturasi tinggi.
  - Dilarang efek neon atau glow sintetis.
  - Dilarang sudut kamera miring acak tanpa makna.
