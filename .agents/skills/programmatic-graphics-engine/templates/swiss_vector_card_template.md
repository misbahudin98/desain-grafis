## 2. CARA PENGGUNAAN CEPAT MELALUI PYTHON

Eksekusi generator bawaan untuk merender kartu berbasis kode langsung ke folder `templates/`:
```bash
python .agents/skills/programmatic-graphics-engine/scripts/generate_svg_card.py
```
Hasil berkas dapat langsung diunggah ke CDN atau disematkan ke tag meta HTML:
```html
<meta property="og:image" content="templates/sample_swiss_card.svg" />
<meta property="og:image:width" content="1200" />
<meta property="og:image:height" content="630" />
```
