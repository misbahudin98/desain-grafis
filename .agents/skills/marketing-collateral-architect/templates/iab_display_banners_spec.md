# Template Spesifikasi IAB Display Banners (iab_display_banners_spec.md)
> **Engine Target:** Marketing Collateral Architect v1.0.0  
> **Standar:** IAB New Ad Portfolio & LEAN Architecture Principles.

---

## 1. 4 FORMAT KANONIKAL IAB DISPLAY BANNERS

```markdown
# IAB CAMPAIGN SPECIFICATION: [NAMA BRAND / KAMPANYE]
- **Batas Bobot Aset:** Awal <= 150 KB, Lanjutan <= 300 KB
- **Loop Animasi:** Maksimal 15 detik (3x Loop)
- **Border:** 1px solid stroke keliling (#CBD5E1) untuk latar terang

---

### UNIT 1: MEDIUM RECTANGLE (300 x 250 px)
- **Tujuan:** In-Article Editorial & Content Stream Integration
- **Layout Grid:** 2 Kolom Vertikal (Kiri: Teks & CTA, Kanan: Visual Hero)
- **Headline Size:** 20px - 24px Bold (Maksimal 4-6 kata)
- **CTA Button Size:** 140 x 36 px (Warna aksen kontras WCAG AAA)
- **Logo Size:** Maksimal tinggi 24px di sudut atas

### UNIT 2: LEADERBOARD (728 x 90 px)
- **Tujuan:** Top-of-Page Brand Awareness Banner
- **Layout Grid:** Horizontal 3 Zona (Kiri: Logo, Tengah: Headline Nilai 1 Baris, Kanan: Tombol CTA)
- **Headline Size:** 18px - 22px SemiBold
- **CTA Button Size:** 130 x 40 px

### UNIT 3: HALF PAGE / LARGE SKYSCRAPER (300 x 600 px)
- **Tujuan:** High-Impact Brand Storytelling on Sidebar
- **Layout Grid:** 3 Blok Vertikal (Atas: Logo & Headline 3 Baris, Tengah: Foto Produk Megah, Bawah: 2 Manfaat + CTA Box)
- **Headline Size:** 26px - 32px Bold
- **Hero Image Height:** 280px

### UNIT 4: BILLBOARD (970 x 250 px)
- **Tujuan:** Desktop Masthead & Premium Takeover
- **Layout Grid:** Panorama 3 Kolom Modular
- **Headline Size:** 32px - 40px Bold Display
```
